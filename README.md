# Cryptoanaliz — анализ BTC по историческим данным

Инструмент командной строки для анализа исторических данных Bitcoin (или
любого другого актива в формате OHLCV): расчёт технических индикаторов и
формирование бычьих/медвежьих сигналов.

## Установка

```bash
pip install -r requirements.txt
```

## Формат входного CSV

Файл должен содержать колонки (регистр и порядок не важны):

- дата: `date` / `time` / `timestamp` / `datetime` / `open_time`
- цена закрытия: `close` / `price` (обязательна)
- необязательно: `open`, `high`, `low`, `volume`

Если `open`/`high`/`low` отсутствуют, они приближаются по `close`.
Если `volume` отсутствует, используется 0.

## Использование

```bash
python main.py --input data.csv --output result.csv --plot chart.png
```

- `--input` — путь к исходному CSV (обязательно)
- `--output` — сохранить CSV с рассчитанными индикаторами (опционально)
- `--plot` — сохранить график (цена/SMA/Bollinger, RSI, MACD) в PNG (опционально)

## Индикаторы

- SMA (20, 50, 200), EMA (12, 26, 50)
- RSI(14)
- MACD (12, 26, 9)
- Полосы Боллинджера (20, 2σ)
- ATR(14)
- Средний объём (SMA 20)

## Сигналы

- Golden Cross / Death Cross (SMA50 × SMA200)
- Пересечение линий MACD
- Перекупленность/перепроданность по RSI (70/30)
- Пробой полос Боллинджера
- Положение цены относительно SMA200 (долгосрочный тренд)
- Аномальный объём (≥2× среднего за 20 периодов)

По совокупности сигналов выводится итоговая оценка настроения рынка
(бычий / медвежий / нейтральный) со скором от -1 до +1.
